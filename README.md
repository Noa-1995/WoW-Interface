# ⚔️ Custom FrameXML — WoW 3.3.5a

> Interfaz personalizada inspirada en el diseño visual de **WoW Retail**, adaptada para la experiencia clásica del cliente **3.3.5a (WotLK)**.

---

## 🇪🇸 Español

Una interfaz FrameXML personalizada para World of Warcraft 3.3.5a, inspirada en el estilo visual de WoW Retail y adaptada a la experiencia clásica.

El proyecto está en desarrollo y se irá ampliando con mucho más contenido y nuevas interfaces en futuras versiones.

### ✨ Contenido actual:

* 🛠️ **Profesiones mejoradas:** Ventana de profesiones ampliada, con mejor organización de recetas.
* 🎒 **Mochila combinada:** Todas tus bolsas en una única ventana unificada estilo Retail.
* 📜 **Mapa de misiones:** Mapa interactivo integrado con panel lateral de misiones.
* 🏰 **Buscador de mazmorras:** Rediseño visual completo basado en las expansiones modernas.
* ⚔️ **Interfaz de PvP:** Nueva presentación para campos de batalla y arenas.
* 🖼️ **HelpFrame UI:** Interfaz de ayuda completamente rediseñada con navegación lateral personalizada, carrusel de anuncios y diseño visual moderno.
* 📋 **Gestor de Addons:** Interfaz completa de gestión de addons con panel de información detallado.

> 🚧 **Proyecto en desarrollo**

Creditos Tambien a: Furioz and s0h2

---

## 🇬🇧 English

A custom FrameXML interface for World of Warcraft 3.3.5a, inspired by the visual style of WoW Retail and adapted for the classic experience.

The project is actively being developed and will receive much more content and new interfaces in future updates.

### ✨ Currently available:

* 🛠️ **Enhanced Professions:** Expanded professions window with improved recipe categorization.
* 🎒 **Combined Backpack:** All your bags merged into a single unified window, Retail style.
* 📜 **Quest Map:** Interactive map featuring an integrated side-by-side quest log.
* 🏰 **Dungeon Finder:** Complete visual redesign inspired by modern expansions.
* ⚔️ **PvP Interface:** New layout and visual presentation for battlegrounds and arenas.
* 🖼️ **HelpFrame UI:** Completely redesigned help interface with custom sidebar navigation, announcement carousel, and modern visual layout.
* 📋 **Addon Manager:** Complete addon management interface with detailed information panel.

> 🚧 **Work in progress** 

Credits also to: Furioz and s0h2x
